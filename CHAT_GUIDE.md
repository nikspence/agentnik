# Chat and history

## Chat: independent conversations with local and cloud models

Open **＋ Chat** to start an independent session. Tabs remain separate even when they share a connection. Agentnik supports OpenAI-compatible **Responses**, **Chat Completions**, and **Anthropic Messages**, plus native Ollama chat. Actual model capabilities depend on the endpoint.

- Stream replies with Markdown and wrapped code blocks; turn streaming off when an endpoint requires it.
- Expand or hide inline thinking, and select reasoning effort for models that support it. Thinking uses smaller, subdued text to distinguish it from the response.
- Copy an assistant response with its original Markdown using the **⧉** icon, including text received so far during streaming.
- Edit and resend a previous prompt with **✎**, restoring its text and images to the composer while preserving earlier history.
- Attach multiple PNG, JPEG, WebP, or GIF images through the file picker, drag and drop, or clipboard paste. Preview them in request order and double-click to open a stored copy. Model image support varies.
- **Document Reader:** attach text/Markdown/CSV/JSON, PDF, DOCX, and XLSX with local preview. PDFs default to page images **and** extracted text for multimodal models; turn off page images for text-only models. Preview/remove document chips, drop documents into the composer, and restore them when editing a sent prompt. Extracted snapshots persist with drafts, history, saved prompts, and JSON exports. Original document binaries are not retained. Files stay local until Send. Limits: four documents per prompt, 10 MB each, 48,000 extracted characters, 100 PDF text pages or 12 image pages per import. Scanned PDFs work through page images; OCR and spreadsheet formula evaluation are not included.
- **Image generation and editing:** enable the image tool in **Settings** and choose an image connection, model, and optional compatible endpoint. Ask the chat model to generate an image or attach a reference and ask for an edit. Generated images appear in the conversation and are retained with its history. Use the preview and save icons beneath an image to inspect it and save an unchanged copy. The previous generated images can be referenced for a follow-up edit. The prompt and selected reference images are sent to the image provider and may incur charges. Image generation does not let the chat model inspect the returned image; uncertain requests are not automatically repeated. Tool and image model support depends on the providers. Image activity records aspect ratio, background, and reference count. Rejections include recognized provider error categories when available; arbitrary provider text, prompts, and image data are not recorded as diagnostics.
- **Calculator / Data tools:** model-requested local arithmetic and bounded CSV/JSON statistics are always available, including without Web. Numeric summaries include missing values and optional groups. Code also has these tools. No arbitrary code executes; results use approximate floating-point arithmetic.
- **MCP in Chat (preview):** configure enabled servers in **MCP servers**, then select and order up to five using the chat's **MCP servers…** button; use **Refresh MCP** after changing configurations. Selecting or reopening a chat does not start the server. Discovery connects without approval when the model requests it, including reconnecting on a follow-up. MCP tools run without approval, including tools that can write or perform external actions. Server annotations are claims by the server, not enforcement; a selected local server runs with your user permissions and may access data. Server results are untrusted and may be sent to the selected model and saved in chat history. A changed or unavailable server must be reselected. User-only annotated text is shown in MCP activity instead of sent as a content block to the model; other fields can repeat the same information. The first selected server wins conflicting MCP tool names. Agentnik discovers the selected servers before calling tools, and a truncated tool list blocks calls when precedence cannot be established. The servers can be used alongside Web and Calculator / Data tools. The toolbar **MCP** switch controls whether selected servers are available to new runs and defaults on to preserve existing selections. Turning it off does not remove a selection. In **Settings**, choose **MCP First** or **MCP Last** for conflicting tool names. With MCP First, Agentnik discovers the selected servers before a conflicting local tool can run. Strict public-only navigation disables MCP in Chat. Chat can list and read text resources and supported resource templates, and retrieve prompts, from each selected server. Reads and retrievals require a current listing from that server, except that assistant-directed resource links returned by a tool can be read from their originating server without a listing. Servers advertising MCP completions can suggest argument values for listed prompts and supported resource templates. Suggestions are untrusted. Resource and prompt contents are untrusted and may be sent to the model; user-only prompt content is shown in activity. When a 2026 server or 2025-06-18/2025-11-25 server requests supported form input, review its message and answer using the form or JSON editor, or decline. Forms support titled choices and multiple-choice lists; more complex schemas use the JSON editor. String-pattern checks are time-bounded and use Agentnik’s regex engine, which can differ from the server’s. For supported 2026 and 2025-11-25 URL-mode requests, review the full HTTPS destination and explicitly choose whether to open it in your external browser; opening signals consent, not completion. When a 2025-11-25 server reports URL input is required, Agentnik asks you to explicitly retry after the external interactions; inspect the server state first because the original operation may have taken actions. Matching completion notifications are shown as untrusted server reports and never trigger a retry. Form answers go to the MCP server and may be returned to the model; cancelling stops the operation. Experimental 2025 task-required tools are supported on capable local and remote servers. The 2026 Tasks extension is supported experimentally for local and remote servers, including reviewed interactive input; 2025 task-associated input is supported; task-augmented input requests remain unsupported. Cancellation does not prove a task stopped. A 2026 server can also request a state-only continuation; Agentnik follows paced rounds within the operation timeout without displaying the opaque state. MCP is never enabled for System One decisions. Cancellation stops further scheduling and closes the session; a submitted call may already have completed. No live model compatibility is implied by the connection or tool listing.

  For a vision-capable model, enable **MCP image input** to send assistant-directed PNG, JPEG, or WebP images from MCP tools, resources, and prompts to the selected connection. Up to four images are included per tool batch, subject to the research context limit. Model-facing results identify each image, and images that do not fit are identified as omitted to the model and counted in activity. Image bytes are available only during the current turn and are not saved in chat history. MCP audio blocks are replaced with notices. Code can inspect supported MCP images when image inspection is enabled.

  Optional server usage guidance is sent to the model as untrusted discovery data. When Chat reconnects automatically and receives guidance, it returns that guidance before executing the requested batch; the model can then choose its next action. Server guidance does not grant permissions or override your instructions.

  If an MCP result exceeds the remaining context budget, Chat may retain its model-facing JSON temporarily for this turn. The model can search it and read ranges without calling the server again. A partial preview and any storage failure are reported; the full artifact is cleared when the turn ends.

  Explicit server errors for resource, prompt, template, and completion requests are returned to the model without automatically retrying. Failed listings are cleared, and a prompt must be listed again after a retrieval error. A connection failure or uncertain tool call still stops the run.

  With Web enabled on the managed route, an unavailable MCP `web_fetch` tool or eligible completed fetch error can fall back to Agentnik-managed public page retrieval. Partial results retain successful MCP content and retry only eligible failed URLs through the managed reader. Access blocks, uncertain calls, timeouts, and requests for cached content only do not trigger this fallback. Managed retrieval may use a configured page provider after a direct fetch fails, as described in the research settings.

  If an MCP request has invalid arguments, Agentnik rejects the entire requested batch before any tools execute and returns validation feedback to the model, which may correct the request within the chat's limits. This does not retry calls already sent to a server.

  **MCP activity** shows the selected server, discovered tool count, tool names, and outcomes, including when a call may have completed despite an error. It does not add tool arguments or returned records to these activity messages.
- Resize the composer; Agentnik remembers its height. Drafts and attachments remain available after failed or cancelled requests.
- Web, MCP, and session controls sit below the conversation, with run status in the status bar.

## System One and earlier Decision sessions

Code can use a configured System One model for optional shell command advice. Earlier Decision sessions open read-only, and the Prompts panel can display saved Decision prompts even without a saved session. For new System One queries with varying states, images, and questions, use [Promptnik](https://github.com/nikspence/promptnik).

## Prompts, history, and everyday controls

- Save chat drafts with **Save prompt**, or star a past message. Give the prompt a name or accept the default. Search the collapsible Prompts panel and restore a prompt with **Copy to tab** or a double-click. Saved prompts survive restarts and history clearing.
- Search, rename, delete, and export saved sessions. Clear all history requires confirmation. Drafts and form edits save automatically; malformed or newer-version records remain preserved as unavailable sessions.
- Images are copied into application storage and shared by content hash, so history survives moved originals. JSON session exports include local attachment paths rather than bundled image files or credentials.
- View reported input/output tokens, current input context, effective context limit when known, elapsed time, and available processing/generation rates. Missing measurements remain unknown; thinking time is an estimate when available.
- Choose light, dark, or system theme in **Settings**; adjust font size from 8–32 points with **A− / A+**. Sidebar visibility and composer sizing are remembered.
- Use **Ctrl+Enter** to send, **Ctrl+B** to toggle history, and **Ctrl+N** for a new chat.
- Select a language preview in **Settings** and restart to try translated controls. Korean, Spanish, French, Simplified and Traditional Chinese, and German are available. The new catalogs use machine translation and need human review, including regional wording and safety-sensitive text. English remains the fallback for untranslated strings.

Background requests keep the interface responsive and tabs independent. Cancellation stops accepting results and scheduling more work; remote processing or billing may continue until the server stops. A shared worker limit bounds background work.

## Chat context compaction

**Context…** can compact completed chat history with the selected model. It creates a summary used for later requests while leaving the original transcript and attachments in the saved session. Inspect and edit the summary in the same dialog, or choose **Use full history** to remove it. Compaction is lossy: review the result for missing details. The model receives the messages and attachments being summarized; recorded research source identifiers and links are supplied, but raw tool exchanges are not replayed in the summary request. The selected model must support any included images.

**Auto compact** is enabled by default. Before a send, Agentnik may make a separate summary request when a rough byte estimate approaches a configured model context limit, or stored tool exchanges approach Agentnik's limit. Configure the connection's context limit for window-based triggering. This estimate is not a token count and cannot guarantee a request fits, especially with images. Automatic compaction uses the selected endpoint and may incur charges; turn it off beside **Context…**. It does not run during a chat or research request. If compaction fails or is cancelled, Agentnik does not send the pending prompt automatically, and the original history stays intact.

## Continuing a limited chat run

When a Chat tool or research run reaches a limit, **Continue** starts a fresh turn with fresh limits, the original request, visible partial answers, and bounded saved source and tool records. Incomplete tool calls are not replayed. Explicitly continued attempts remain available on later turns, subject to context compaction and provider limits. The unsent composer draft and its attachments remain untouched. Check research activity for complete saved source details.
